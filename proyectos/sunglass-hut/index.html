Sunglass Hut Summer Event

Diseñar para la interacción, el contenido y la conexión

Categoría
Evento
Cliente
Equipo Singular
Lugar
Barcelona

Celebrado en Barcelona este verano, el Sunglass Hut Summer Event reunió a influencers y creadores de contenido para descubrir las últimas colecciones de gafas de la marca.

Concebido como una experiencia de marca inmersiva, el evento mostró distintos estilos y categorías de producto en un ambiente vibrante y social, pensado para fomentar el descubrimiento, la interacción y la creación de contenido.
